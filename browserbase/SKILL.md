# Browserbase Browser

Облачный браузер. Работает без окна на экране пользователя. Для задач в окнах Windows используйте `windows-mcp`.

Требует `BROWSERBASE_API_KEY` в переменных пользователя и сервер `browserbase` в `opencode.json` без `disabled`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `start` | Создать сессию браузера или переиспользовать существующую по `sessionId` |
| `navigate` | Открыть URL (`url`) |
| `observe` | Найти элементы на странице по описанию (`instruction`) |
| `act` | Выполнить действие на странице (`action`): нажать, ввести текст, выбрать |
| `extract` | Извлечь данные по инструкции (`instruction`) |
| `end` | Закрыть сессию |

Все инструменты, кроме `start`, принимают необязательный `sessionId`. Без него используется текущая активная сессия.

## Типовой порядок

1. `start` — создать сессию, запомнить `sessionId`.
2. `navigate` — открыть страницу.
3. `observe` — проверить, какие элементы доступны, перед действием.
4. `act` — выполнить действие (клик, ввод, выбор).
5. `extract` — получить нужные данные.
6. `end` — закрыть сессию, когда работа завершена.

## Правила

- Перед `act` вызывать `observe`, чтобы не действовать вслепую.
- Сессии закрывать через `end`, иначе они занимают ресурсы аккаунта.
- Не вводить пароли и секреты через `act` без явной просьбы пользователя.
- Не заходить на сайты с платными или необратимыми действиями (оплата, удаление, отправка) без подтверждения пользователя.
