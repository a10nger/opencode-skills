# Sherlock

Поиск учётных записей по имени пользователя — [sherlock-project/sherlock](https://github.com/sherlock-project/sherlock).
Проверяет ~400 сайтов и возвращает те, где ник существует.

## Установка (уже выполнена)

```
D:\Apps\sherlock\.venv\Scripts\sherlock.exe
```

Версия на момент установки: v0.16.2. Обновление:

```powershell
$env:UV_PIP=''
& 'D:\Apps\uv\uv.exe' pip install --python 'D:\Apps\sherlock\.venv\Scripts\python.exe' --upgrade sherlock-project
```

## Workflow

1. Запустить проверку ника (вывод только найденного, без ANSI-мусора):

   ```powershell
   D:\Apps\sherlock\.venv\Scripts\sherlock.exe <ник> --timeout 10 --print-found --no-color
   ```

2. Если сайтов слишком много и проверка тянется долго — ограничить список:

   ```powershell
   D:\Apps\sherlock\.venv\Scripts\sherlock.exe <ник> --site GitHub --site Reddit --site Steam --timeout 10 --print-found
   ```

3. Сохранить отчёт в файл (рядом появятся `<ник>.txt` и `<ник>.csv`):

   ```powershell
   D:\Apps\sherlock\.venv\Scripts\sherlock.exe <ник> --timeout 10 --print-found --no-color --folderoutput D:\Apps\sherlock\out
   ```

4. Найденные ссылки вернуть пользователю списком. Открыть вручную не пытаться —
   `--browse` есть, но под агента не нужен.

Полезные флаги: `--timeout N`, `--site NAME`, `--print-all` (показывать и ненайденное),
`--nsfw` (включать NSFW-сайты), `--csv`, `--xlsx`, `--tor` / `--proxy`.

## Как читать результат

- Строка `[+] Name: https://...` — ник существует на сайте.
- Один ник ≠ один человек: популярные ники (`alex`, `max`) дают десятки чужих профилей.
  Для «своего следа» сверять только те площадки, где пользователь реально регистрировался.
- Ложные срабатывания бывают: сайт отдаёт 200 на любую страницу. Спорные ссылки проверять глазами.
- `[!]` и таймауты — сайт заблокировал запрос или недоступен, это не «не найден».

## Ограничения

- Только проверка существования страницы; содержимое профиля не читается.
- Сеть медленная/нестабильная: без `--timeout` часть сайтов висит. Ставить 10 секунд.
- Некоторые сайты (X/Twitter, Instagram) отдают блокировку без прокси — это норма.
- Инструмент публичный и легальный, но массовый прогон чужих ников может нарушать ToS площадок:
  для чужих профилей — только точечные проверки.
