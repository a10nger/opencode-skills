# Delegate

Цель — не жечь облачные токены на механике. `local-worker` работает на локальном qwen3:8b и стоит ноль, но ошибается чаще.

## Что делегировать

- Прочитать файл и вернуть конкретные строки/факт.
- Найти файлы по шаблону, найти вхождения строки.
- Одна правка в одном файле с точно известным содержимым.
- Запустить известную команду (сборка, тест, `git status`) и вернуть результат.
- Собрать вывод: версии, размеры, список процессов.

## Что делать самому

- Больше 2 файлов или правки взаимозависимы.
- Требования размытые — сначала надо решить **что** делать.
- Безопасность: секреты, права, удаление данных, реестр, сеть.
- Дизайн/архитектура, ревью, объяснение Trade-offs.
- Воркер уже провалил этот шаг дважды.

## Формат задачи

Нумерованный план, ≤15 строк, без воды:

```
1. Прочитай C:\path\file.json и верни строки 10-25 дословно.
2. В C:\path\x.ts замени 'old' на 'new' (единственное вхождение).
3. Запусти: git -C C:\work\repo status --short
4. Верни отчёт по формату ниже.
```

Обязательно:
- **абсолютные пути** (у воркера другой cwd);
- точная команда целиком, а не «проверь сборку»;
- явное «не делай ничего кроме перечисленного»;
- не более одного действия на пункт.

Нельзя:
- «посмотри и исправь если надо» — воркер начнёт импровизировать;
- передавать задачу с условием «если X, то сделай Y, иначе Z» — не удержит;
- просить «покажи файл целиком» — контекст 32k, ответ обрежется.

## Формат ответа воркера (8 строк)

```
1. Итог: сделано | не сделано
2. Что изменено: <файл: строка / команда>
3. Команды: <что запускал>
4. Результат: <exit code / ключевая строка>
5. Ошибки: <текст или "нет">
6. Не сделано: <что и почему>
7. Нужно от меня: <да/нет + что>
8. Уверенность: высокая | средняя | низкая
```

Если отчёт не по формату или «уверенность: низкая» на важном шаге — проверять факт самостоятельно, а не дословно верить.

## Батчинг

Независимые шаги отправлять **одним** промптом (пункты 1–5), а не пятью вызовами: каждый вызов — холодный старт и повтор контекста.

## Признаки провала (забирать себе)

- Воркер утверждает «готово», но файл не изменился.
- Правит не тот файл / создаёт дубликат вместо правки.
- Игнорирует абсолютный путь и работает в своей папке.
- Дважды возвращает одну и ту же ошибку.
- Выдумывает содержимое файла вместо чтения.

## Цена

Каждый вызов воркера — время (8B на 4060: 25–45 tok/s) и риск. Мелкая задача на 3 строки иногда быстрее делается напрямую. Делегировать, когда шаг действительно механический, а не «на всякий случай».
