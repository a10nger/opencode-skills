# Docs Lookup

Память модели отстаёт от реальности. Для всего, что версионируется (API, CLI, SDK, конфиг-схемы), источник истины — официальная документация, а не воспоминания.

## Порядок

1. `websearch` — найти **канонический URL** (официальный домен, не блог-перепечатку).
2. `webfetch` — прочитать нужную страницу в `markdown`.
3. Если страница не открывается — попробовать `raw.githubusercontent.com` для README/схемы, `.../llms.txt` если есть.
4. Выжимку — **в файл** в `C:\Users\zhega\AppData\Local\Temp\opencode\docs-<тема>.md`.
5. В чат — только вывод: 3–7 строк + путь к файлу.

## Куда смотреть по темам

| Тема | Первоисточник |
|---|---|
| OpenCode | `https://opencode.ai/docs/` |
| JSON-схема конфига OpenCode | `https://opencode.ai/config.json` |
| llama.cpp | `http://127.0.0.1:8081/v1/models` |
| MCP | `https://modelcontextprotocol.io/docs` |
| GitHub API | `https://docs.github.com/en/rest` |
| PowerShell | `Get-Help <cmd> -Online` (локально, без сети) |
| npm-пакет | `https://www.npmjs.com/package/<name>` + README в репо |

Локальное предпочтительнее сетевого: `Get-Help`, `--help`, `man`, файл `CHANGELOG.md` в самом пакете.

## Проверка версии

Прежде чем доверять примеру из доков — сверить версию:

```powershell
node --version
& D:\Apps\node\node.exe --version   # если нода поставлена в D:\Apps
git --version
```

Пример для v3 и v5 часто отличается, а страница документации показывает только актуальную версию и не предупреждает об удалённых полях.

## Что фиксировать в выжимке

- Точный URL и **дата** обращения.
- Версия, к которой относится.
- Минимальный рабочий пример, а не описание.
- Что явно deprecated.

Не копировать в файл простыню страницы: страница на 5000 слов превращается в 200 строк факта.

## Антипаттерны

- Отвечать «как я помню» на вопрос про сигнатуру/поле конфига.
- Пересказывать документацию в чат, когда нужен один флаг.
- Брать код из StackOverflow 2019 года без сверки версии.
- Верить описанию в поисковой выдаче вместо самой страницы.

## Если веб недоступен

Сказать прямо: «проверить не могу, отвечаю по памяти, версия могла измениться». Не выдавать догадку за факт — особенно в конфигах, где неверный ключ молча игнорируется.
